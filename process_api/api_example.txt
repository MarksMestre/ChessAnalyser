# Chess.com archive-list URL, used only when --player is not given.

# Copy this file to api.txt and put your own username in it:
#
#   copy api_example.txt api.txt
#
# Both are public, login-free endpoints, so there is no key here and nothing
# secret to protect -- api.txt is git-ignored only so your username stays out of
# shell history and out of the repository.
#

# covers this command and every other one.
#
